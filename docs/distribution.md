# GitHub distribution

Teamute’s release DMGs are ad-hoc signed only: they are not Developer ID signed
and are not notarized by Apple. For normal installation and macOS security
guidance, see the [README](../README.md#install-teamute).

Release-maintainer instructions, including tag/version validation, checksum
verification, and retry guidance, are maintained in
[DEVELOPING.md](../DEVELOPING.md#github-release-distribution).
